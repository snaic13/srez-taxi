# 🌐 Инструкция: Как выложить сайт в интернет

Ваш сайт готов! Файл: `website/index.html`

---

## 🚀 Способы публикации (от простого к сложному)

### **Способ 1: GitHub Pages** (Бесплатно, 5 минут) ⭐

**Самый простой способ!**

1. **Создайте аккаунт на GitHub** (если нет): https://github.com

2. **Создайте новый репозиторий:**
   - Нажмите "New repository"
   - Имя: `srez-taxi` (или любое другое)
   - Сделайте репозиторий **Public**
   - Нажмите "Create repository"

3. **Загрузите файл:**
   - Нажмите "uploading an existing file"
   - Перетащите `index.html` из папки `website/`
   - Нажмите "Commit changes"

4. **Включите GitHub Pages:**
   - Зайдите в Settings → Pages
   - Source: выберите "main" branch
   - Нажмите Save

5. **Готово!** Ваш сайт будет доступен через 1-2 минуты по адресу:
   ```
   https://ваш-username.github.io/srez-taxi/
   ```

---

### **Способ 2: Netlify** (Бесплатно, 2 минуты) ⭐⭐

**Ещё проще!**

1. Зайдите на https://netlify.com
2. Зарегистрируйтесь (можно через GitHub)
3. Перетащите файл `index.html` прямо на главную страницу Netlify
4. Готово! Сайт автоматически опубликован

**Адрес будет примерно:** `https://случайное-имя.netlify.app`

**Чтобы изменить адрес:**
- Site settings → Change site name → введите `srez-taxi`
- Получите `https://srez-taxi.netlify.app`

---

### **Способ 3: Vercel** (Бесплатно, 3 минуты)

1. Зайдите на https://vercel.com
2. Зарегистрируйтесь
3. Нажмите "Add New" → "Project"
4. Перетащите папку `website/` или загрузите через GitHub
5. Нажмите Deploy

**Адрес:** `https://srez-taxi.vercel.app`

---

### **Способ 4: Свой домен** (Платно, от 200₽/год)

Если хотите красивый адрес типа `srez.taxi`:

1. **Купите домен:**
   - https://reg.ru — 200-500₽/год
   - https://nic.ru
   - https://timeweb.com

2. **Выберите хостинг:**
   - **Netlify/Vercel** — подключите свой домен (бесплатно)
   - **Timeweb** — от 150₽/мес
   - **Beget** — от 120₽/мес

3. **Загрузите файл** на хостинг через FTP или панель управления

## 📝 Пошаговая инструкция для GitHub Pages

### Шаг 1: Откройте GitHub
Зайдите на https://github.com и нажмите **Sign up** (если нет аккаунта)

### Шаг 2: Создайте репозиторий
1. Нажмите зелёную кнопку **"New"** (или плюс в правом верхнем углу)
2. **Repository name:** `srez-taxi`
3. ✅ Отметьте **Public**
4. ✅ Отметьте **Add a README file**
5. Нажмите **Create repository**

### Шаг 3: Загрузите файл
1. В репозитории нажмите **Add file** → **Upload files**
2. Перетащите файл `index.html` из папки `website/`
3. В поле "Commit changes" напишите: `Add main page`
4. Нажмите **Commit changes**

### Шаг 4: Включите GitHub Pages
1. Перейдите в **Settings** (вкладка вверху)
2. В левом меню найдите **Pages**
3. В разделе **Source** выберите:
   - Branch: **main**
   - Folder: **/ (root)**
4. Нажмите **Save**

### Шаг 5: Подождите 1-2 минуты
GitHub автоматически опубликует сайт. Обновите страницу Settings → Pages

Вы увидите:
```
✅ Your site is live at https://username.github.io/srez-taxi/
```

**Готово!** Скопируйте ссылку и делитесь с кем угодно! 🎉

## 🎨 Как изменить сайт после публикации

### GitHub Pages:
1. Откройте файл `index.html` в репозитории
2. Нажмите иконку карандаша (Edit)
3. Внесите изменения
4. Нажмите **Commit changes**
5. Сайт обновится автоматически через 1-2 минуты

### Netlify:
1. Перетащите новую версию файла на сайт Netlify
2. Сайт обновится мгновенно

## ❓ Частые вопросы

**В: Это бесплатно?**  
О: Да! GitHub Pages, Netlify и Vercel полностью бесплатны для таких сайтов.

**В: Сколько людей может зайти?**  
О: Миллионы. У этих сервисов нет ограничений по трафику для статичных сайтов.

**В: Нужно ли продлевать?**  
О: Нет, сайт будет работать бесконечно бесплатно.

**В: Как добавить свой домен?**  
О: Купите домен на reg.ru, затем в настройках GitHub Pages укажите "Custom domain".

**В: Цены настоящие?**  
О: Цены рассчитываются по реальным тарифам такси + учитывается время суток и расстояние. Близко к реальным ценам (±10-15%).
